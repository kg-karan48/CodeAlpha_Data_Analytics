# CodeAlpha Data Analytics Internship

This repository contains the projects I completed during my CodeAlpha Data Analytics Internship.

## Completed Tasks

### Task 1 - Exploratory Data Analysis (EDA)
Analyzed an e-commerce dataset using Python and Pandas.

- Checked data structure and data types
- Checked missing and duplicate values
- Performed statistical analysis
- Identified trends and patterns
- Generated business insights

### Task 2 - Sentiment Analysis
Analyzed customer reviews using Natural Language Processing.

- Cleaned review text
- Calculated sentiment polarity
- Calculated subjectivity
- Classified reviews as Positive, Negative, or Neutral
- Created sentiment visualizations
- Identified common words
- Generated business insights


### Task 3 - Data Visualization
Created visualizations from e-commerce sales data.

- Sales and profit analysis
- Category and region analysis
- Top products analysis
- Sales and profit distributions
- Correlation analysis
